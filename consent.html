How to Get Access

Brand: Nickolas Pearson · Last updated October 1, 2026

Nickolas Pearson operates a software application that manages a private home media server for one family. Approved users can text it a movie title, and the application adds the movie and replies with a confirmation. It is not open to the public, and nobody can use it without giving consent first.

How consent works

Consent is collected verbally, before anyone can use the service. The owner, Nickolas Pearson, personally asks each family member, in person or by phone:

"I set up a private text number for my home movie server. Text it a movie title and it adds the movie and texts you back. Message and data rates may apply, frequency varies, text STOP to opt out or HELP for help. Want to be able to text it?"

If the family member says yes, the owner adds their phone number to the approved list and gives them the service number. The application sends messages only to approved numbers. Numbers that are not approved receive no replies.

Service number

(385) 462-6769, for approved family members only.

Message details

  • Messages are informational only: confirmations and status updates about movie requests. There is no marketing or promotional content.
  • Message frequency varies and depends on how often you send requests.
  • Message and data rates may apply.
  • Reply STOP at any time to stop receiving messages. Reply HELP for help.
